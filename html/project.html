Creating a project

Learn to create a project

Making a repository and making changes together with other people can seem scary but this page is a step-by-step guide to creating, linking and inviting other collaborators to the project.

Creating a new project

  • Create a local project
    • The first thing that need to be done is creating a local project and then typing in git init in the terminal. This will initiate a hidden directory in the project folder called .git which enables communication with Github. To see that the hidden project has been created, type Ls -a the command line.
  • Create a repository
    • After a local project has been created, navigate to the repositories tab on your github profile and press "New". Choose a name for you repository and choose the visibility. A public repository can be viewed by anyone while with a private one the creator chooses who can specific people to collaborate with. When done, press "Create repository".
  • Linking the two
      On the next screen, navigate to "...or push an existing from the command line". There should be three lines of code that we want to copy and paste one by one into the terminal in VS Code.
    • git remote add origin git@github.com:your-account/repo/.git
        • This line connects your local project and the github together.
    • git branch -M main
        • This renames the default branch to "main". This is the most important branch in the project as it stores the stable and final code. The main branch can be renamed but it is not suggested to do so.
    • git push -u origin main
        • This pushes the local code to the repository (origin).
  • Pull
    • Now your project is synchronized with your repository but there will now be two copies of the code base, the local one on your computer and the one stored in the repository. When working on a team (and always just to get into the habit) you should always git pull to ensure that you have the latest version of the project locally. As soon as someone pushes to the repo then your local code is out of date and you need to pull the latest version.

    • In the main page (<code>) of your repository, look for a button called "<> code" and click on the SSH tab. copy the snippet of code with this format "git@github.com:user/project-name.git". The owner of the repository should do this and share the link with their collaborating partners.
