Git Commands

A beginner-friendly reference for commonly used Git commands.

Getting Started

$ git init

Creates a new Git repository in the current folder.

$ git clone <url>

Creates a local copy of an existing remote repository.

Prepare Changes

$ git status

Shows changed, staged and untracked files.

$ git add <file>

Adds a specific file to the staging area.

$ git add .

Adds all current changes to the staging area.

$ git diff

Shows unstaged changes in the working directory.

Save Changes

$ git commit

Creates a commit and opens an editor for the commit message.

$ git commit -m "message"

Saves staged changes with a commit message.

Branches

$ git branch

Lists the local branches in the repository.

$ git switch <branch-name>

Switches to an existing branch.

$ git switch -c <branch-name>

Creates a new branch and switches to it.

$ git branch -d <branch-name>

Deletes a local branch that is no longer needed.

Merge Changes

$ git merge <branch-name>

Combines changes from another branch into the branch you are currently on.

Remote Repositories

$ git remote add origin <url>

Connects a local repository to a remote repository.

$ git fetch

Downloads information from the remote without merging it.

$ git pull

Downloads remote changes and integrates them into the current branch.

$ git push

Sends local commits to the connected remote branch.

$ git push -u origin <branch-name>

Pushes a new branch to the remote and sets its tracking branch.

Undo & Restore

$ git restore <file>

Discards unstaged changes made to a file.

$ git restore --staged <file>

Removes a file from the staging area without deleting its changes.

History

$ git log

Shows the commit history of the repository.

$ git log --oneline

Shows the commit history in a shorter one-line format.

$ git log --graph

Displays the commit history as a branch and merge graph.
