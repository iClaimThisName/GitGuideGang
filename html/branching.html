Branches

Branches are a necessary part of Github. It's what makes us have the ability to freely code without without risking any potential mess. This page will show you how to create branches and how to close(delete) them.

Creating a branch

$ git branch <branch-name>

This command creates a local branch. Commonly used for when you want to create a new branch, but still keep working on the current branch you're on.

$ git checkout -b <branch-name>

This command will create and switch to the newly added branch. Used commonly for when you want to immediately work on a new branch. Before using this command remember to add and commit your changes, so that you don't lose any unsaved changes.

$ git push -u origin <branch-name>

This command will push a local branch to Github. This will make the local branch into a remote branch on your repository, which we can then use to make changes freely without conflicting with any of the other branches.

Closing a branch

$ git branch -d <branch-name>

This command will delete the selected branch you have chosen, but only if if you have merged it first. Otherwise it will show a error.

$ git branch -D <branch-name>

This command will forcefully delete the selected branch regardless if it's merged or not. Please be 100% sure that you're deleting the right branch as any unsaved changes will be removed.
