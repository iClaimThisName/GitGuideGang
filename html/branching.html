Branches

Branches are a necessary part of Github. It's what makes us have the ability to freely code without without risking any potential mess. This is done by creating a personal branch that we can then merge with main when everything looks clean.

Creating a branch

To create a branch we start by typing the command $ git branch <branch-name>. However this will only create the branch. In order to switch to the branch we just created we use the command $ git checkout -b <branch-name>. After that make sure that you're on the right branch which you can do by typing $ git status. Alternatively you can use the command $ git checkout -b <branch-name> which will create the branch and also switch to it immediately.
