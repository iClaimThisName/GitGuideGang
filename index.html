Github
A website where you can store your project's repository and share it with other collaborators. You can also track issues here and review other people's code before it gets added to the project.
Alternatives to Github are Bitbucket and Gitlab
Git
Git is the software that allows you to keep track of your project's history. It is the version control system that you can then host and share on platforms like Github.
You can use Git without using Github, but you can't use Github without using Git
Pros of Using Version Control
Store
Keep your projects on a remote location so you can access it even if your computer breaks
Share
Work together with other people
Review
Review changes before they get implemented
Track
Keep track of issues and their statuses
Revert
Go back to older versions of the code in case you need to undo changes
Protect
Keep your projects safe by making changes on branches first before adding them to the main project
